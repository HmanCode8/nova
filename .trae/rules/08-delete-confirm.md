# SKILL：删除确认交互规范（唯一人工确认项）
技能描述：本项目权限模型中，只有文件删除操作需要人工确认，其余全部自主执行

## 适用工具范围
- file_delete：删除文件 / 文件夹

## 交互流程
1. Agent 决定调用 file_delete，传入路径
2. Middleware 工具链中间件拦截：
   - 先做白名单路径校验（不在白名单直接拒绝，不弹确认）
   - 校验通过后，识别为删除操作 → 触发 LangGraph `interrupt()` 中断
3. 后端推送删除确认事件到前端：
   ```json
   {
     "type": "delete_confirm",
     "confirm_id": "uuid",
     "path": "要删除的文件/文件夹路径"
   }
   ```
4. 前端弹出确认弹窗，展示完整路径 + 危险提示 + 【确认删除】【取消】按钮，支持语音确认
5. 用户确认 → 后端 resume() 恢复 Graph，执行真实删除，返回结果
6. 用户取消 → 工具返回「用户已取消删除」，Agent 继续对话
7. 超时：3 分钟未响应自动判定取消，释放 Graph 状态，避免卡死

## 硬校验前置（无条件执行）
1. 路径必须在白名单目录内
2. 敏感系统目录（C:\Windows、/System 等）默认禁止删除，直接拒绝

## 强制约束
1. 删除是唯一不可绕过的人工确认项，禁止任何方式静默删除
2. 后台长任务中的删除操作同样必须人工确认，不允许后台静默删除
3. 删除确认事件也写入 Trace 日志（状态为 waiting_confirm / confirmed / cancelled）
4. 支持鼠标点击确认 + 语音确认（语音模块完成后接入）

## 超时处理
删除确认超时自动取消，不阻塞其他任务；Graph 断点由 MemorySaver 保存，可恢复
