# SKILL：UI专项规范
技能描述：控制前端视觉风格，实现科技感桌面Agent界面

## 整体基调
深色科技风格，深色底色 + 低饱和蓝青主色；粒子背景；毛玻璃面板；克制不花哨，优先可读性。

## 界面组成
1. 悬浮球：常驻桌面，科技粒子球体，三种状态（idle/listening/thinking）；透明、无边框、置顶、可拖拽、Alpha穿透；全局快捷键唤起
2. 三栏工作台：
   - 左栏资讯雷达：数据源列表、分类标签、星标收藏、【放入问题】按钮
   - 中间对话+任务：流式对话、工具调用折叠面板、后台任务卡片（进度/日志/停止）
   - 右栏看板：自定义数据卡片，多Tab切换
   - 三栏支持拖拽调宽、收起展开
3. 轨迹 Trace 面板：
   - 时序时间线（甘特样式），展示每次工具调用
   - 每条：工具名、参数、返回结果、耗时、时间
   - 支持搜索、展开详情
4. 顶部导航：对话/轨迹/我的关注/它对我的了解/全局语音开关
5. MCP 商店：卡片画廊、搜索、分类、安装/配置按钮，对标TRAE插件市场样式
6. 删除确认弹窗：明确展示要删除的路径，确认/取消按钮 + 语音确认支持

## 语音交互
- 全局语音开关，聆听状态有波形动画
- 输入框支持按住说话

## 响应式
宽屏三栏，窄屏自动收起侧栏变单栏对话；移动端可读
