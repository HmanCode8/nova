# SKILL：安全与权限规范
技能描述：定义本项目权限模型，重点区分「自主执行」与「唯一人工确认项」

## 核心权限模型（务必严格遵守）
| 操作 | 权限 |
|---|---|
| 读取文件 | ✅ 自主执行 |
| 新建/编辑/写文件 | ✅ 自主执行 |
| 打开文件 | ✅ 自主执行 |
| 截屏 | ✅ 自主执行 |
| 执行命令 | ✅ 自主执行（白名单目录内） |
| 联网搜索 | ✅ 自主执行（开关可控） |
| 调用 MCP | ✅ 自主执行 |
| 剪贴板读取 | ✅ 自主执行 |
| **删除文件/文件夹** | ⛔ **强制人工确认** |

## 强制规则
1. **目录白名单兜底**：Agent 只能访问用户配置的白名单目录；白名单之外路径一律拒绝；这是防止触碰系统敏感目录的核心防线
2. **删除确认不可绕过**：`file_delete` 调用前必须通过 LangGraph `interrupt()` 中断，返回待确认事件到前端；用户确认后才执行，取消则终止。禁止任何绕过方式静默删除
3. 敏感系统路径（C:\Windows、/System、用户凭证目录等）默认不在白名单，禁止访问
4. 命令执行限制在白名单目录内；禁止访问外网敏感地址、禁止破坏性系统命令
5. 密钥只在 .env，禁止硬编码；前端拿不到密钥
6. 本地优先：文件、截图、对话记录默认不上传云端，除非用户主动配置第三方 API
7. 所有工具调用写入 Trace 日志（无论放行还是待确认），供轨迹面板回放
8. 后台任务中的删除操作同样必须人工确认，不允许后台静默删除

## 图片链路安全
- image_ocr / image_vl 的图片 base64 只在运行时临时传递，不持久入库，只存识别后的文本摘要
- screen_capture 截屏为自主执行，但结果同样遵守「不入库原始图，只存摘要」

## 禁止行为
❌ 绕过删除确认
❌ 访问白名单外路径
❌ 上传本地数据到未授权云端
❌ 后台任务静默执行删除
